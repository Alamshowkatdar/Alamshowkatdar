# Alam Showkat

I build local-first, open-source tools that turn everyday hardware into useful controllers and utilities.

Most recent project: **[lemoGamePad ultimate](https://alamshowkatdar.github.io/lemoGamePad-ultimate/)** — turn an Android phone into a real gamepad for a Windows or Linux PC over Wi-Fi, USB or Bluetooth.

## Projects

| Project | What it does | Links |
| --- | --- | --- |
| **lemoGamePad ultimate** | Use an Android phone as a virtual Xbox 360 / DualShock 4 gamepad for PC games, with up to eight players, a browser pad and PC screen preview. No account, no cloud, no dongle. | [Website & downloads](https://alamshowkatdar.github.io/lemoGamePad-ultimate/) · [Source](https://github.com/Alamshowkatdar/lemoGamePad-ultimate) · [Latest release](https://github.com/Alamshowkatdar/lemoGamePad-ultimate/releases/latest) |
| **igi-mobile** | Android game and tooling experiments. | [Source](https://github.com/Alamshowkatdar/igi-mobile) |
